# Landing RedBarrioAnimal

Aplicación React + Vite para presentar las dos propuestas conceptuales del grupo 28 (bloque S02-A). No integra servicios, APIs, backend ni automatizaciones.

## Desarrollo local

Desde la raíz del repositorio, instalá las dependencias e iniciá Vite:

```powershell
npm install
npm run dev
```

También se puede iniciar Vite desde esta carpeta con `npm run dev`.

## Validación

Desde la raíz del repositorio:

```powershell
npm run build
npm run lint
```

La consigna, los datos de asignación y el registro del proceso están en el [README del proyecto](../README.md) y en [consignas.md](../consignas.md).
